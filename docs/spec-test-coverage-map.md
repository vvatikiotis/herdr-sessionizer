# SPEC-to-test coverage map

Audit baseline: `193175e` (`test/full-spec-coverage`), the commit that contains the current `SPEC.md` and `docs/spec-test-coverage-plan.md`. The Rust suite was run in this audit with `cargo test --all-targets`: **37 passed** (21 `tests/commands.rs`, 12 `tests/directory_config.rs`, 2 `tests/shell_pool.rs`, 2 `tests/workspace_exit.rs`). The Python regressions were not rerun.

This is an audit artifact only. It does not change the product or `SPEC.md`.

## Evidence rules

- **Candidate stream** means a stub captured the rows or reload input. It does not prove that fzf rendered, highlighted, or accepted that identity.
- **Rendered/accepted identity** means the real-fzf PTY observed the visible row, or the accepted action/output proved which row was selected.
- **Historical live pass** means the result recorded in `SPEC.md` from an earlier local run. It is not a fresh result from this audit.
- **Static manifest** means direct inspection of `herdr-plugin.toml`; it is not evidence that Herdr delivered the registered event.
- Status is `covered`, `partial`, `missing`, or `environment-limited`. A historical pass is not treated as a current rerun.

## Remaining approved slices

These are the smallest remaining audit/test slices named by the current plan. They are not new requirements.

- **#13 discovery:** add executable-boundary assertions for built-in depth-three defaults versus checked-in depth-four data, `foreground_cwd` and first-pane fallback, selection-time failure for an unavailable explicit include, unreadable-root/permission-specific limitation, and any missing cleanup/no-navigation assertions tied to those failures.
- **#14 navigation/pool:** add shell-pool delegate failure with no ordinary-create retry; complete pane-exit no-surviving-user, still-existing source, focus-preservation, event/timeout, and focus-failure boundaries only where required by the existing specification.
- **#15 manifest:** directly assert `herdr-plugin.toml` identifier, minimum version, Linux/macOS platforms, startup hook, `workspace.focused` hook, `pane.exited` hook, and absence of a picker binding. Keep this separate from live event delivery.
- **#16 real fzf:** rerun or extend isolated PTY coverage for warning non-selectability, retained workspace rows across the specified query classes, first displayed-match acceptance, filtered-position/directory fallback, Ctrl-Space and cancellation, and stale-agent retry. Preserve the six dismissal cases and treat timeout/forced termination as failures.

No product or specification change is authorized by these gaps. No deployment, push, or main-branch change is part of this audit.
